# Contributing to Kepner-Tregoe Codebase

Thank you for working with this Kepner-Tregoe (KT) codebase. To support ongoing improvement and knowledge sharing, we ask that all modifications be submitted back to KT as outlined below.

## 🔁 Sharing Modifications

Please share back any of the following:
- Bug fixes or patches
- Feature enhancements
- Updated documentation or setup instructions
- Feedback on implementation or usage

## 📦 How to Share

You may submit updates through one of the following:
- **Pull Request (Preferred)**: If you have write access to this repo, create a new branch, push your changes, and open a pull request.
- **Email Submission**: If you do not have write access, email a `.zip` or `.tar.gz` archive of your changes to your KT contact or Shane Chagpar schagpar@kepner-tregoe.com

## ✅ Guidelines

- Clearly document changes you make.
- Do not remove or alter any existing license or copyright notices.
- Ensure any shared updates do not include third-party code unless licensed appropriately and clearly identified.

## 📧 Need Help?

Please reach out to your KT representative if you have any questions about contributing or using this code.

---

_All contributions are reviewed before being accepted into any future KT-maintained version of this codebase._
